# 🧪 WildRoute – Manual QA Testing

## 📌 Project Overview

**WildRoute** is a web application that was manually tested as part of my **Software Quality Assurance portfolio**.

The purpose of this testing project was to evaluate the application's functionality, user interface, navigation, form behaviour, responsiveness, and overall usability.

Testing was performed manually to identify defects, verify expected behaviour, and document the results using structured QA documentation.

---

## 🎯 Testing Objective

The main objective of this testing project was to verify whether the application functions as expected from an end-user perspective.

The testing focused on:

* Verifying application functionality
* Checking navigation and links
* Validating user inputs and forms
* Checking UI elements and layouts
* Testing responsive behaviour
* Identifying functional defects
* Identifying UI and usability issues
* Documenting defects with clear reproduction steps
* Recording test execution results

## 📊 Test Execution

Test cases were executed manually against the application.

The following statuses were used:

| Status           | Description                                     |
| ---------------- | ----------------------------------------------- |
| **Pass**         | Actual result matched the expected result       |
| **Fail**         | Actual result did not match the expected result |
| **Not Tested**   | Test case was not executed                      |
| **To Be Tested** | Test case is pending execution                  |
